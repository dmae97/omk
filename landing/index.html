Product

Start with one agent.
Build your own workflow.

Read files, edit code, run commands, and save sessions. Add subagents, MCP tools, or verification workflows when you need them.

Optional subagent workflows

Configure a team when the task needs one.

Subagents require an extension and agent definitions. Scoped lane primitives support configured workflows; installing OMK does not turn every prompt into parallel work. The animation is an illustrative overview of an optional workflow.

Goal acceptance checks

You define what “done” checks.

Approve an acceptance command with /goal verify. A goal completes on a passing check and fresh evidence. The result covers that command’s checks, not every possible bug.

Provider-neutral

Switch models. Keep your session.

Use /model to switch between configured providers. Subscription logins, API keys, and local models share one CLI session. Availability depends on your provider setup.

Session recovery

Pause now. Pick up later.

Sessions save automatically. Return with omk -c or /resume. The animation illustrates session recovery; after restarting, approve a goal’s acceptance check again.

How it works

Choose. Work. Check. Resume.

  1. 01

    Choose a model

    Start OMK in your repository. Use /login for a supported provider, then /model to choose a model.

  2. 02

    Try a first task

    Ask for a read-only repository summary first. A fresh install starts one agent; subagents and MCP tools require setup.

  3. 03

    Give a goal an acceptance check

    Set /goal <objective>, then approve a command with /goal verify <command>. A failing check continues work, up to the eight-round limit.

  4. 04

    Review the result and return later

    Inspect the diff and check output. An open goal’s passing evidence becomes stale after a workspace edit. Saved sessions let you return with omk -c.

Install

Try it in your repository.

Requires Node.js 22.19 or newer. Install, enter your project, and run /login then /model. Built-in local bash requires sandbox-exec on macOS or bwrap and unprivileged user namespaces on Linux. See the quickstart and platform requirements. 

npm install -g open-multi-agent-kit --ignore-scripts
omk --version
cd your-project
omk

Docs & FAQ

Straight answers.

Is OMK a coding agent or an orchestrator?

open-multi-agent-kit is a standalone terminal coding-agent CLI. It starts with one agent. Subagents require configured extensions, and protocol verification requires an explicit workflow. OMK is not a plugin for Claude Code or OpenCode.

Which models are supported?

Supported subscriptions, API-key providers, and local models are documented in the provider guide. Use /model to switch between configured models without starting a new session.

How is completion verified?

Ordinary prompts settle after their tool loop; they do not certify correctness. With /goal verify <command>, a goal completes only when the approved check passes and its evidence still matches the workspace. A weak check can complete a goal early. See the acceptance-check contract and evidence and limits.

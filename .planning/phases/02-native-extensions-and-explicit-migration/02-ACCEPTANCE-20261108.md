### Compiled Bun

Root cause: Bun 1.3.4 and later build standalone executables that do not read on-disk `package.json` at runtime unless built with `--compile-autoload-package-json`. A minimal Bun 1.4.4 executable outside OMK reproduced it: `main`, root `exports` and subpath exports in `node_modules` failed, and only `index.*` fallbacks resolved. Plain `bun` succeeded. The same probe built with the flag resolved the archived `installed` fixture's CJS and ESM subpaths. CI pins Bun 1.3.10 and is affected.

Fix: both compile commands (`scripts/build-binaries.sh`, `packages/coding-agent/package.json` `build:binary`) pass the flag. Regression: `scripts/test/bun-compile-package-json.test.mjs`. It failed first, with the static contract and a real executable returning `Cannot find module` for all three probes, and passed after the change.

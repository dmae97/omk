# Project agent guide

Start with the installed `.omk/skills/pstack/poteto-mode/SKILL.md` after any host-required gates. If it is unavailable, continue directly. Route real dependencies with the available AdaptOrch MCP when they change work order or verification. Routing is advice, not permission to delegate or spend.

Pick one `TASKS.md` item and its acceptance check. Read `PRD.md` for scope, `ARCHITECTURE.md` for ownership, `DESIGN.md` for user-facing behavior and `RULES.md` for constraints. Resume from `PROGRESS.md`. Run the acceptance check and record its exact outcome there.

대상: [기존 G1 B1 번들](g1-b1-review.md), [라이선스 원문 보완](g1-license-review.md),
[6개 버전 소스 이력](g1-source-history.md) 및 [기계 판독 체크리스트](g1-source-history.json)의
`approvalChecklist` 16개 항목. 검토일: 2026-11-13.

**미승인 상태입니다.** 자료가 존재한다는 표시와 권리/채택 승인은 다릅니다.
아래 박스는 사람이 판정할 때까지 비워 둡니다. 소스 조회 요청을 빌드/편입/배포 승인으로
해석하지 않으며 K1은 모든 항목의 범위 밖입니다.

## 1. ObjC 고지: B1 판단 전에 필요한 자료

| ID | 현재 상태 / 판단 역할 | 필요한 증거와 수용 조건 |
| --- | --- | --- |
| N1 | 자료 확보 / 검토자 | 6개 exact archive의 Rust 파일 759개를 main/generated blob에 연결한 표를 확인. 759/759 일치는 출처 증거이며 고지 완결성/권리 증명은 아님 |
| N2 | 파일/원출처 구체화, 미승인 / 라이선스 검토자 | [전체 main-file 범위](g1-objc-notice-scope.md)와 [후속 원출처](g1-objc-notice-origins.md): 미매핑 16파일, 나머지 이름 18개와 원래 commit/당시 고지 맥락을 연결. 공동기여자 3명의 선택 main-file commit 연결을 개인 소유 행으로 바꾸지 않음. 생성 파일 561개와 개인 고지 완결성은 별도 미해결 |
| N3 | 파일/원출처 구체화, 미승인 / 라이선스 검토자 | 기존 Steven 30파일/과거 MIT 후보 182파일은 유지. 남은 16파일은 고지 삭제 후 2025년 추가된 것으로 도입 source/선언/정책을 대조했지만 개인 고지 완결성은 미확인. 선언/정책을 고지 전문/기여자 동의로 대체하거나 나중 Mads 본문 소급, 미매핑 면제, 전체 소유 단정 금지 |
| N4 | 부분 증거, 미승인 / 라이선스 검토자 | [복사/고지 매핑](g1-rust-copy-notices.md)의 `e1c7b209…` 복사 도입, 당시 `a0061acd…` Darwin 원본/발행본 대조와 MIT/REUSE 고지, 별도 `1e5719bd…` compiler 참조를 확인. **단일 복사 SHA 미확증**을 명시적으로 판정하고 원문/변경 범위를 P1에 연결. 같은 작성자라는 이유로 조건을 지우거나 Rust 대안을 MIT-only ObjC 전체에 부여하지 않음 |
| N5 | 선언 확인, 미선택 / 소유자와 라이선스 검토자 | MIT-only 3개와 triple-license 3개를 구분해 실제 선언된 대안만 검토. open 재라이선스 제안이나 나중 일반 본문으로 새 대안을 부여하지 않음 |

- [ ] N1 확인
- [ ] N2 전체 main-file 근거와 미확인 개인/생성 파일 고지 범위 판정
- [ ] N3 최초/후대 고지 근거를 구분하고 원문 보존 행/material과 P1 추가 범위 판정
- [ ] N4 원문/블록 매핑 검토, 단일 복사 SHA 미확증과 P1 고지 보존 범위 판정
- [ ] N5 선택 대안과 적용 범위 기록

제출할 고지 표의 최소 열: `crate@version`, archive hash, 현재 파일, 과거 source revision/path,
원문 copyright/permission 출처와 hash, 적용 범위, 누락/미확인 사항, 검토자와 판정일.
이름이나 연도를 추정해 새 copyright 문구를 만들지 않습니다.
N4의 [기계 판독 매핑](g1-rust-copy-notices.json)은 원문 27개 hash와 파일/범위별 근거를
추가했지만, N4 판정자/판정일과 모든 승인란은 여전히 비어 있습니다.

## 2. Apple SDK 권리: 남은 확인 항목

검토한 약관은 [Apple 공개 PDF](https://www.apple.com/legal/sla/docs/xcode.pdf)의 EA2002,
날짜 표기 `06/08/2026`, SHA-256
`5e6bd16bcba3dd591bde1c57f7c6f19f08a194c84cdc54485c4660f90e2a26ec`입니다.
원문 발췌/페이지는 기존 보완 JSON의 `A-*`에 있습니다. 공개 PDF가 실제 적용/수락 계약이라는
증거는 아닙니다. SDK/계약 확인을 위해 지금 설치나 약관 동의를 실행하지 않습니다.

- [ ] A1 문서상 provenance와 실제 증빙의 구분 확인

- [ ] A3 미래 빌드 환경과 증빙 수집 책임/절차 결정
- [ ] A4 배포 예정 material별 권리 분류안 검토
- [ ] A5 조건부 허용/제한/필요한 추가 근거에 대한 기록된 판단
- [ ] A6 예외 의존 여부와 원문 의무 기록
- [ ] A7 배포 채널/제품 범위와 별도 계약 필요성 기록

A5는 법률 검토가 필요한 경우의 인계 항목입니다. 이 문서는 특정 준거법의 강행규정,
API 저작권성 또는 계약 효력에 대한 법률 결론을 내리지 않습니다. 적용 지역/사실관계가
빠진 상태에서 권리 확인을 완료로 표시하지 않습니다.

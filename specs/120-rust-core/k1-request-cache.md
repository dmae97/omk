# K1 explicit Anthropic request cache

Date: 2026-11-17
Status: implemented bounded source unit; full K1 and migration remain incomplete.

## Independent expectations

The real Node `streamAnthropic`, model registry, in-memory AuthStorage and SDK recorded
32 new requests before any Rust implementation. Sources include actual cache-boundary,
Unicode sanitization, compatibility, message transformation and tool-schema owners, with
SHA-256 provenance. Numeric-loopback library and actual executable tests each compare
all 74 requests (the earlier 10 dispatch/32 policy requests plus 32 cache requests), exact
body bytes/non-runtime headers, projected semantic events/results. Rust receives inputs,
not expected outputs. Original corpora, catalog artifact and dependency graph are unchanged.

Recording uses isolated homes, synthetic API keys, network-isolated synthetic-only fetch,
explicit retention and zero retries. Freshness checks are non-rewriting. Unknown/failed
expectations never become new golden output generated by Rust.

## Implementation

- Explicit `options.cacheRetention`: none, short or long. Long uses `ttl:"1h"` only when
  compatible; Fireworks defaults to no long TTL and no tool cache unless explicitly overridden.
- Final supplied tool cache follows compatibility. Existing raw tool-schema/argument
  serialization is retained. Tool definitions in this corpus are already Node-stable;
  arbitrary schema normalization/order/locale collation is not implemented by this unit.
- Cache the final converted user text/image/tool-result block, after existing filtering,
  orphan resolution and grouping. A last assistant or empty conversation stays uncached.
  Wrapping the existing typed block preserves wire key order and raw arguments.
- System cache uses `systemPromptCacheBoundary` in UTF-16 units and optional boolean
  `systemPromptCacheBoundaryBypass`. Missing metadata permits whole-system caching.
  Valid positive integral metadata caches only the stable prefix. Invalid explicit
  metadata, including null, disables system cache without disabling message/tool cache.
  End-of-string creates no empty suffix. Split surrogate pairs lose unpaired units,
  matching actual Node sanitizeSurrogates rather than inserting replacement characters.
- Boundary deserialization retains missing versus present null. Invalid cache enum/shape,
  null retention and nonboolean bypass are refused locally; refusal equivalence to every
  malformed Node caller value is not claimed. Synthetic replay still refuses new policies.

Omitted retention deliberately preserves the bounded adapter's old no-cache behavior.
No ambient/default-retention inference, cache-affinity/session key, OAuth client, provider
billing/cache hit or real API acceptance is implemented. Complete arbitrary-tool request
parity, remaining providers/APIs/authentication storage and later core/session/platform
migration requirements remain open in [spec.md](spec.md) and [tasks.md](tasks.md).
